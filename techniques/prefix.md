# Prefix Sum

i-th result should be the sum of all elements 0 to i:

```js
result[i] = numbers[0] + numbers[1] + numbers[2] + ... + numbers[i]
```

# Prefix Array

i-th result should be the product of all elements from 0 to i:

```js
result[i] = numbers[0] * numbers[1] * numbers[2] * ... * numbers[i]
```
